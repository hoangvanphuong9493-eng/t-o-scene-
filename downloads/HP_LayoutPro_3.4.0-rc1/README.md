# HP Layout Pro 3.4.0-rc1

Bản thử nghiệm sửa lỗi view nhỏ và các phương án Quick Layout trùng nhau trên bản 3.3.0-rc1.

- [Tải plugin RBZ](HP_LayoutPro_v3.4.0-rc1.rbz?raw=true)
- [Hướng dẫn và kết quả kiểm tra](HUONG_DAN_3.4.0-rc1.md)
- [SHA-256](SHA256SUMS.txt)

Cài bằng Extension Manager rồi khởi động lại SketchUp. Bấm Cập nhật, mở Quick Layout và chọn **Khít giấy — hình lớn nhất trong ô**. Có 8 chiến lược chia trang, ảnh xem trước và lọc bố cục trùng. Với các trang cũ, dùng Khít trang/Khít tất cả; kiểm tra lại chú thích vẽ tay.

Đã đọc dữ liệu bố cục trong TES.skp; kiểm tra hồi quy và giao diện bằng ảnh mô phỏng, chưa dựng hình học model thực trong SketchUp 2023 Windows. Xem hướng dẫn trước khi dùng bản RC cho hồ sơ phát hành. PDF vẫn là ảnh, CAD vẫn là 3D.
