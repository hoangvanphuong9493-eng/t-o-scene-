# HP Layout Pro 3.3.0-rc1

Bản thử nghiệm tối ưu bố trí bản vẽ nội thất/tủ từ Scene cho SketchUp 2023 Windows.

- [Plugin RBZ](HP_LayoutPro_v3.3.0-rc1.rbz?raw=true)
- [Báo cáo kiểm tra PDF](BAO_CAO_E_LOAN.pdf?raw=true)
- [Hướng dẫn và kết quả chi tiết](BAO_CAO_KIEM_TRA.md)
- [Mã kiểm tra SHA-256](SHA256SUMS.txt)

Cài RBZ qua Extension Manager rồi khởi động lại SketchUp. Dùng bản sao model để thử: chọn A3 dọc cho tủ cao hoặc A2 ngang cho cụm rộng, Quick Layout tối đa 2 view hoặc 1 view/trang. In đúng khổ giấy ở 100% / Actual size.

25 kiểm tra logic và luồng dữ liệu đạt trên Linux; chưa nghiệm thu trong SketchUp 2023 Windows, CAD thực hoặc bản in. PDF vẫn là ảnh ghép trang; CAD là DWG/DXF 3D; chưa tự tạo hồ sơ LayOut hoặc CAD hình chiếu 2D.

Các tệp này được đăng công khai theo sự đồng ý của người dùng. Hai tệp đính kèm gốc không được đăng vào thư mục phát hành này.
